Core concept

What is HTML?

HTML stands for HyperText Markup Language. It gives web content structure by identifying headings, paragraphs, links, lists, images, forms, and other page elements.

Working model

HTML structures the content. CSS controls the visual presentation. JavaScript adds interactivity.
